# Nike Financial Performance Dashboard

Independent finance portfolio project by Tosin Thompson.

## Live dashboard
This repository is set up to publish the dashboard with GitHub Pages.

## What this project demonstrates
- Financial statement analysis
- Ratio analysis
- Five-year trend analysis
- Business communication
- Data visualization
- Basic front-end web development

## Data
Public Nike SEC Form 10-K filings for fiscal years 2024, 2025, and 2026. Those filings include comparative figures used to construct the FY2022–FY2026 series.

## Run locally
Open `index.html` in a browser. No build step or external library is required.
